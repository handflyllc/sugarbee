How to Build & Test
Compile the integrated engine using gcc:

Bash
￼
￼
gcc main.c vcart.c -o sugarbee -lSDL2 -llua
Run Default Mode (Mock Cartridge):

Bash
￼
￼
./sugarbee
Boots cleanly, loads the mock cartridge, prints game metadata, and enters the main loop.

Test Guru Meditation (Version Mismatch):
Pass a dummy or mismatched file as an argument to watch vcart_parse_header() intercept the failure and fire the Guru Meditation screen:

Bash
￼
￼
./sugarbee invalid_game.vcart




Compilation & Usage Instructions
Compile sbee-pack:

Bash
￼
￼
gcc sbee-pack.c vcart.c -o sbee-pack
Create a Game Directory:

Bash
￼
￼
mkdir -p my_game
echo "function update() end function draw() sugarbee.cls(10, 40, 10) sugarbee.print('HELLO FROM VCART!', 100, 100, 255, 255, 255, 3) end" > my_game/main.lua
Pack into a .vcart File:

Bash
￼
￼
./sbee-pack -i my_game -o hello_world.vcart -t "Hello World Demo"
Launch with SugarBee Engine:

Bash
￼
￼
./sugarbee hello_world.vcart


Prerequisites & Dependencies
To build with ZIP extraction support, ensure zlib and minizip developer headers are installed:

Bash
￼
￼
# Debian / Ubuntu / Raspberry Pi OS
sudo apt install libz-dev libminizip-dev


Compilation & Testing Flow
Compile Engine with minizip and zlib:

Bash
￼
￼
gcc main.c vcart.c -o sugarbee -lSDL2 -llua -lz -lminizip
Test End-to-End Pipeline:

Bash
￼
￼
# Package the game directory using sbee-pack
./sbee-pack -i my_game -o test.vcart -t "SugarBee In-Memory Test"

# Run directly with the host engine
./sugarbee test.vcart
